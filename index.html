MeatScentinel
interface prototype

An IoT-based multi-gas sensing and web application system using a Rule-Based Decision Fusion Algorithm for Fresh and Spoiled classification of raw chicken, beef, and pork. The two interfaces below run on separate devices — the touchscreen sits on the inspection chamber, while the web application runs in the inspector’s browser.

IoT Device — LCD Touchscreen
Sample selection, placement validation, gas detection, gas-based result, upload status, and chamber ventilation.
Open
Web Application
Inspector login, dashboard, inspection records, review queue, record details with decision fusion, and account.
